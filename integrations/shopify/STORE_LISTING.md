## Introduction

## Description

RapidAct adds a clear, configurable disclosure for storefronts that use an AI
assistant or another visitor-facing AI system.

Install the app, open the theme editor, enable the RapidAct app embed and enter
the details visitors should see. The badge can identify the AI system, name the
responsible organisation and link to further information.

The storefront assets are bundled with the theme app extension and served by
Shopify. RapidAct does not edit theme files and removes cleanly when the app is
uninstalled.

## Feature list

- Add a floating AI disclosure badge through a theme app embed
- Configure the system name, responsible organisation and visitor message
- Link visitors to a detailed notice or evidence page
- Choose English, Spanish, German, French or Italian
- Select the badge position and accent colour
- Use locally bundled storefront assets served by Shopify

## Review instructions

1. Install RapidAct on the development store through the standard OAuth flow.
2. Open the embedded RapidAct app in Shopify admin.
3. Select **Open the theme editor**.
4. Enable **RapidAct AI disclosure** under App embeds.
5. Enter a Badge ID such as `6b88b63`, a system name and the responsible
   organisation, then save.
6. Open the storefront. A RapidAct disclosure badge appears in the configured
   bottom corner.
7. Select the badge to read the system name, organisation and further-
   information link.

The app requests no Admin API scopes and does not require protected customer
data.
