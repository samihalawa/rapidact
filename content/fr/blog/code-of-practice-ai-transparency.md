# Le Code de bonnes pratiques sur la transparence de l'IA : ce que signer (ou pas) signifie pour vous

*2026-07-25 · Équipe RapidAct*

En juin 2026, la Commission européenne a publié le Code de bonnes pratiques final sur la transparence du contenu généré par IA — le compagnon volontaire de l'Article 50, avec un set d'icônes «IA» standard de l'UE et deux sections de mesures : une pour les fournisseurs, une pour les déployeurs.

## Ce que le Code est (et n'est pas)

- **Volontaire.** Signer signale la bonne foi et donne une posture de défense de type présomption ; ne pas signer n'est pas une violation.
- **Pratique.** Il traduit «divulguer clairement» en schémas concrets : où vont les étiquettes, quelles icônes utiliser, comment formuler les avis.
- **Division fournisseur/déployeur.** Les fabricants de modèles et plateformes ont des devoirs de marquage technique ; les déployeurs (vous) ont des devoirs de divulgation visible.

## Ce qu'un petit site devrait en prendre

1. Utilisez les **icônes IA standard de l'UE** plutôt que d'inventer votre propre design d'étiquette — reconnaissabilité instantanée, zéro travail de design.
2. Suivez ses **modèles de formulation** pour la divulgation de chat («Vous interagissez avec un système d'IA…»).
3. Gardez des **preuves de processus** — le Code met l'accent sur des mesures démontrables, ce qui est exactement ce qu'un journal de preuves fournit.
