# Marquage lisible par machine

**Métadonnées techniques intégrées au contenu généré par IA (filigranes, provenance style C2PA) permettant aux machines de détecter l'origine IA. Obligatoire pour les fournisseurs d'IA générative selon l'Art. 50(2) ; les anciens systèmes ont jusqu'au 2 décembre 2026.**

> C'est la couche fournisseur — invisible pour les humains, lisible par les machines. Différente des étiquettes visibles que les déployeurs doivent afficher.
