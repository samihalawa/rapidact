# Plugin di disclosure IA vs strumenti di consenso cookie

**I banner cookie erano la categoria installa-e-dimentica del GDPR; la disclosure IA è l'equivalente dell'AI Act. Il pattern è identico: la regolazione crea il dovere, il plugin lo implementa. Ma l'Articolo 50 richiede più di un banner — rilevamento, etichette per contenuto ed evidenza.**

| | Consenso cookie (GDPR) | Disclosure IA (AI Act) |
|---|---|---|
| Trigger | Raccolta dati | Interazione/contenuto IA |
| UI | Un banner | Avviso per widget + etichette per contenuto |
| Prova | Registri del consenso | Registro delle prove di disclosure |
| Rilevamento necessario | Cookie/tracker | 52+ piattaforme IA |

## Il verdetto onesto

Se hai imparato il playbook del banner cookie nel 2018, capisci già questo mercato. La differenza: la disclosure IA deve prima trovare cosa c'è sul tuo sito — ecco perché lo scanner guida.
