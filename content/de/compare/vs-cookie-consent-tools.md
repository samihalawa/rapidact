# KI-Disclosure-Plugins vs. Cookie-Consent-Tools

**Cookie-Banner waren die Install-and-forget-Kategorie der DSGVO; KI-Disclosure ist das Äquivalent des AI Act. Das Muster ist identisch: Regulierung schafft die Pflicht, das Plugin implementiert sie. Aber Artikel 50 braucht mehr als ein Banner — Erkennung, Labels pro Inhalt und Evidenz.**

| | Cookie-Consent (DSGVO) | KI-Disclosure (AI Act) |
|---|---|---|
| Auslöser | Datenerhebung | KI-Interaktion/-Inhalt |
| UI | Ein Banner | Hinweis pro Widget + Labels pro Inhalt |
| Nachweis | Consent-Aufzeichnungen | Disclosure-Evidence-Log |
| Nötige Erkennung | Cookies/Tracker | 52+ KI-Plattformen |

## Das ehrliche Urteil

Wer 2018 das Cookie-Banner-Spielbuch gelernt hat, versteht diesen Markt bereits. Der Unterschied: KI-Disclosure muss zuerst finden, was auf Ihrer Website ist — darum führt der Scanner.
